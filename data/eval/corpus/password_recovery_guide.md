# Account Access Recovery

When a user cannot sign in, walk them through recovery without mentioning vendor error
codes.

## Steps

1. Confirm the account email is correct.
2. Send a one-time recovery link from the identity portal.
3. Ask the user to choose a new credential and sign in again.
4. If the portal is unavailable, escalate to the identity on-call rotation.

This guide is written in plain language so **semantic / dense** retrieval can find it even
when the user does not reuse exact product tokens.
